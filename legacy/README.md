# 키프 Keep

친구·지인과의 약속을 **약속증서**로 남기고, 기한이 지나면 **단계적으로 재촉**하도록 돕는 웹앱입니다. (멀티모달콘텐츠 수업 MVP)

- 가입·서버 없이 동작합니다. 약속은 각자의 휴대폰 브라우저(localStorage)에 저장됩니다.
- 서명 요청, 서명 완료, 재촉, 연장·분할 요청, 이행 신고는 **압축된 링크**로 주고받습니다(카톡·QR).
- 증서가 확정되면 당사자·금액·기한·서명 획을 묶은 SHA-256 확인코드가 발급되어 위변조를 검사할 수 있습니다.

## 구성
- `index.html` — 앱 전체(HTML·CSS·JS 한 파일)
- `qrcode.js` — QR 생성 라이브러리 [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) 1.4.4 (MIT)

## 주의
키프는 약속의 증거를 남기는 도구이며 법률 자문이 아닙니다. 증서는 공증·강제집행력이 있는 문서가 아닙니다.
